# Placeholder images

Drop real photos here using these names. Until a file exists, components fall back to
`https://placehold.co/WIDTHxHEIGHT` URLs.

| Pattern         | Used for                   | Example                        |
| --------------- | -------------------------- | ------------------------------ |
| `hero.jpg`      | Home page hero image       | `hero.jpg`                     |
| `service-N.jpg` | Service cards (N = 1–8)    | `service-1.jpg`                |
| `doctor-N.jpg`  | Doctor portraits (N = 1–3) | `doctor-1.jpg`                 |
| `clinic-N.jpg`  | Clinic gallery             | `clinic-1.jpg`, `clinic-2.jpg` |

Use JPG, roughly 1600px wide for hero/clinic, 800px for services, 600px for doctors.
